02. Projects

Featured Project

ScoreMax

A multi-sport schedule and live-score app covering Basketball (NBA/NCAA), Soccer (Premier League, La Liga, Bundesliga, Serie A, Ligue 1, MLS, Champions League), NFL, MLB, NHL, and Cricket. Users get live scores, expandable game details — scorers, box scores, stat leaders — and can reorder tabs to put their favorite sports first.

Data comes from ESPN's free public API (no key required). The app is built as a responsive web app and ships to iPhone as a native app via Capacitor, with a custom icon and launch screen.

  • React 19
  • TypeScript
  • Vite
  • Capacitor / iOS
  • ESPN API
