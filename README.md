# Personal Portfolio — Khawar Khan

A simple, fast, dependency-free portfolio site built with plain HTML, CSS, and JavaScript.
No build step required.

## Structure
- `index.html` — page content (hero, about, projects, skills, contact)
- `styles.css` — all styling, light/dark theme, responsive layout
- `script.js` — theme toggle, mobile nav, scroll animations

## Run locally
Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 5173
```

Then visit http://localhost:5173

## Customize
- Replace placeholder project cards in `index.html` with your real projects.
- Add your GitHub / LinkedIn links (search for `href="#"`).
- Swap the `KK` photo placeholder for a real image.

## Deploy
Drag the folder into [Netlify](https://app.netlify.com/drop), or push to GitHub and
enable GitHub Pages, or deploy with Vercel — all free for static sites.
